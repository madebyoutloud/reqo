While the default `reqo` instance works for simple use cases, you can create custom client instances with specific configurations for different APIs or use cases.

## Creating a Client
Use the `createClient` function to create a new client instance:

```ts
import { createClient } from '@outloud/reqo'

const apiClient = createClient({
  url: 'https://api.example.com',
  timeout: 10000,
  headers: {
    'Authorization': 'Bearer your-token'
  }
})

// Use the client
const users = await apiClient.$get('/users')
```

### Options
::field-group
  ::field{name="id" type="string | undefined"}
    Descriptive name for the client, will be used in errors and debugging.
    
    ```ts
    const client = createClient({ 
      id: 'github-api' 
    })
    ```
  ::

  ::field{name="url" type="string | undefined"}
    Base URL for all requests. Paths will be appended to this URL.
    
    ```ts
    const client = createClient({ 
      url: 'https://api.example.com/v1' 
    })
    
    // GET https://api.example.com/v1/users
    await client.$get('/users')
    ```
  ::

  ::field{name="headers" type="Record<string, any> | undefined"}
    Default headers to include in all requests.
    
    ```ts
    const client = createClient({
      headers: {
        'Authorization': 'Bearer token',
        'X-API-Key': 'key'
      }
    })
    ```
  ::

  ::field{name="timeout" type="number | false"}
    Request timeout in milliseconds, applied to each attempt. Set to `false` to disable timeouts.
    <br>
    <br>Defaults to `60000` (60 seconds). With [retries](/guide/retry#timeouts-and-retries), the timer restarts for every attempt and waits between attempts don't count.
    
    ```ts
    const client = createClient({ 
      timeout: 5000  // 5 seconds
    })
    ```
  ::

  ::field{name="totalTimeout" type="number | false | undefined"}
    Timeout of the whole request in milliseconds, including all retries and the waits between them. When it passes, the request rejects with a `TimeoutError`.
    <br>
    <br>Defaults to `false` (no limit). See [Timeouts and Retries](/guide/retry#timeouts-and-retries).
    
    ```ts
    const client = createClient({ 
      timeout: 30_000,       // each attempt
      totalTimeout: 120_000  // whole request
    })
    ```
  ::

  ::field{name="retry" type="UserRetryOptions | boolean"}
    Retry configuration. Set to `true` for default retry behavior or provide custom options.
    <br>
    <br>Defaults to `false`.
    
    ```ts
    const client = createClient({
      retry: {
        limit: 3,
        methods: ['GET', 'HEAD', 'OPTIONS', 'PUT', 'DELETE'],
        statusCodes: [408, 429, 500, 502, 503, 504],
        delay: (state) => state.retryCount * 1000
      }
    })
    ```
  ::

  ::field{name="redirect" type="RequestInit['redirect']"}
    How to handle redirects: `'follow'`, `'error'`, or `'manual'`.
    <br>
    <br>Defaults to `'follow'`.
    
    ```ts
    const client = createClient({ 
      redirect: 'manual' 
    })
    ```
  ::

  ::field{name="fetch" type="typeof fetch"}
    Custom fetch implementation. Useful for testing or using polyfills.
    <br>
    <br>Defaults to `globalThis.fetch`, looked up on every request, so a `fetch` replaced after the client is created is still used, e.g. by msw's `setupServer().listen()` or OpenTelemetry and Sentry instrumentation. Passing `undefined` uses the default too.
    <br>
    <br>In reqo 2.0 and earlier the default captured `globalThis.fetch` when the client was created.
    
    ```ts
    import nodeFetch from 'node-fetch'
    
    const client = createClient({ 
      fetch: nodeFetch as any
    })
    ```
  ::

  ::field{name="validate" type="ValidateFn | undefined"}
    Custom response validation function. By default, responses with `ok: false` throw errors.
    
    ```ts
    const client = createClient({
      validate: (response) => {
        // Only accept 200 status
        return response.status === 200
      }
    })
    ```
  ::
::

## Multiple Instances
Create different clients for different APIs:

```ts
import { createClient } from '@outloud/reqo'

// GitHub API client
const github = createClient({
  id: 'github',
  url: 'https://api.github.com',
  headers: {
    'Accept': 'application/vnd.github.v3+json',
    'Authorization': `token ${process.env.GITHUB_TOKEN}`
  },
  timeout: 5000
})

// Internal API client
const internalApi = createClient({
  id: 'internal',
  url: 'https://internal-api.company.com',
  headers: {
    'X-API-Key': process.env.INTERNAL_API_KEY
  },
  retry: {
    limit: 3,
    delay: (state) => state.retryCount * 2000
  }
})

// Use the clients
const repos = await github.$get('/users/username/repos')
const data = await internalApi.$get('/data')
```

## Base URL Resolution
The client intelligently resolves URLs:

```ts
const client = createClient({
  url: 'https://api.example.com/v1'
})

// Absolute URLs override base URL
await client.$get('https://other-api.com/data')
// GET https://other-api.com/data

// Relative paths are appended
await client.$get('/users')
// GET https://api.example.com/v1/users

await client.$get('users')
// GET https://api.example.com/v1/users

// Get url
client.getUrl('items')
// https://api.example.com/v1/items

// Browser environment - relative base URLs
const browserClient = createClient({
  url: '/api/v1'  // relative to window.location.origin
})
```

## Accessing Configuration

Get the base URL from a client instance:

```ts
const client = createClient({
  url: 'https://api.example.com',
  headers: {
    'X-Custom-Header': 'value'
  }
})

console.log(client.baseUrl)  // 'https://api.example.com'
console.log(client.options)  // { timeout: 60000, headers: { ... }, ... }
```

## Client Class
You can also extend the `Client` class for more advanced use cases:

```ts
import { Client, type ClientOptions } from '@outloud/reqo'

class ApiClient extends Client {
  constructor(options: Partial<ClientOptions> = {}) {
    super({
      url: 'https://api.example.com',
      ...options
    })
    
    // Setup hooks or custom logic
    this.on('request', (config) => {
      console.log(`Making ${config.method} request to ${config.url}`)
    })
  }
  
  // Add custom methods
  async getCurrentUser() {
    return this.$get('/me')
  }
  
  async uploadFile(file: File) {
    const formData = new FormData()
    formData.append('file', file)
    return this.$post('/upload', { data: formData })
  }
}

const api = new ApiClient()
const user = await api.getCurrentUser()
```

::note
`Client` only adds the method shortcuts on top of `BaseClient`, which holds the request logic, options and hooks. Extend `BaseClient` directly if you want to expose your own set of methods, or [`SchemaClient`](/guide/schema-client) if your API has an OpenAPI schema.
::

## Per-Request Overrides
Options passed to individual requests override client defaults:

```ts
const client = createClient({
  timeout: 5000,
  headers: {
    'X-Default': 'value'
  }
})

// Override timeout for this request
await client.$get('/slow-endpoint', {
  timeout: 30000, // overrides client timeout
  headers: {
    'X-Default': 'overridden',  // Replaces default header
    'X-Custom': 'additional'    // Adds new header
  }
})
```
