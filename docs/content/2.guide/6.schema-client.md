---
title: Schema Client
description: Fully typed requests inferred from an OpenAPI schema.
---

The schema client wraps the regular client with types generated from an OpenAPI schema. Paths, path parameters, query parameters, request bodies and response data are all inferred — without writing a single generic.

## Generating Types

Generate the TypeScript definitions from your OpenAPI document with [openapi-typescript](https://openapi-ts.dev/):

```bash
npx openapi-typescript ./openapi.yaml -o ./api.ts
```

This produces a `paths` interface describing every endpoint of your API.

## Creating a Client

Pass the generated `paths` interface to `createSchemaClient`:

```ts
import { createSchemaClient } from '@outloud/reqo'
import type { paths } from './api.js'

const api = createSchemaClient<paths>({
  url: 'https://api.example.com',
  headers: {
    'Authorization': 'Bearer token'
  }
})
```

::note
`createSchemaClient` accepts the same [client options](/guide/instances#options) as `createClient`.
::

## Making Requests

The client exposes the same [method shortcuts](/guide/basic-usage#method-shortcuts) as the regular client, but the `url` argument is restricted to the paths defined in your schema, and only to those that support the given method.

```ts
// Path is autocompleted and checked against the schema
const events = await api.$get('/special-events')
// events is typed as SpecialEventCollection

// Unknown paths are a type error
await api.$get('/unknown')
// ^ Argument of type '"/unknown"' is not assignable to ...

// So are methods the path does not support
await api.$post('/museum-hours')
// ^ Argument of type '"/museum-hours"' is not assignable to ...
```

### Path Parameters
Use the OpenAPI path template as the url and fill it with `params`. Keys are typed from the schema's `parameters.path`.

```ts
const event = await api.$get('/special-events/{eventId}', {
  params: { eventId: 'dad4bce8-f5cb-4078-a211-995864315e39' }
})
// GET /special-events/dad4bce8-f5cb-4078-a211-995864315e39
```

### Query Parameters
`query` is typed from the schema's `parameters.query`.

```ts
const events = await api.$get('/special-events', {
  query: {
    startDate: '2024-01-01',
    endDate: '2024-01-31',
    limit: 10
  }
})
```

### Request Body
`data` is typed from the operation's `requestBody`.

```ts
const event = await api.$post('/special-events', {
  data: {
    name: 'Mermaid Treasure Identification and Analysis',
    location: 'Under the seaaa 🦀 🎶 🌊.',
    eventDescription: 'Join us as we review and classify a rare collection.',
    dates: ['2023-09-05', '2023-09-08'],
    price: 30
  }
})
```

### Responses
Methods without the `$` prefix return the full `Response` object with a typed `data` property, exactly like the regular client. The data type is inferred from the operation's successful (2XX) JSON response.

```ts
const response = await api.get('/special-events/{eventId}', {
  params: { eventId: '123' }
})

console.log(response.status)
console.log(response.data) // SpecialEvent
```

## Full Example

```ts
import { createSchemaClient } from '@outloud/reqo'
import type { paths } from './api.js'

const api = createSchemaClient<paths>({
  id: 'museum-api',
  url: 'https://api.example.com',
  retry: { limit: 2 }
})

api.on('request', (config) => {
  config.headers.set('Authorization', `Bearer ${getToken()}`)
})

// List events
const events = await api.$get('/special-events', {
  query: { limit: 10 }
})

// Create an event
const created = await api.$post('/special-events', {
  data: {
    name: 'Mermaid Treasure Identification and Analysis',
    location: 'Under the seaaa 🦀 🎶 🌊.',
    eventDescription: 'Join us as we review and classify a rare collection.',
    dates: ['2023-09-05'],
    price: 30
  }
})

// Delete it again
if (created.eventId) {
  await api.$delete('/special-events/{eventId}', {
    params: { eventId: created.eventId }
  })
}
```

## Extending the Client

`SchemaClient` is exported as a class, so it can be extended like the regular [Client](/guide/instances#client-class):

```ts
import { SchemaClient, type ClientOptions } from '@outloud/reqo'
import type { paths } from './api.js'

class MuseumApi extends SchemaClient<paths> {
  constructor(options: Partial<ClientOptions> = {}) {
    super({
      url: 'https://api.example.com',
      ...options
    })
  }

  getEvent(eventId: string) {
    return this.$get('/special-events/{eventId}', { params: { eventId } })
  }
}

const api = new MuseumApi()
const event = await api.getEvent('123')
```

## Limitations

- Only JSON media types are resolved for response data, other content types fall back to the raw content map.
- Response types are inferred from successful status codes (`200`, `201`, `202`, `203`, `204`, `206`, `207` and `2XX`). Error responses are not typed and are available as `error.data`.
- Header and cookie parameters are not typed, set them through the `headers` option.
