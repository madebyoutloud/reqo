# @outloud/reqo 2.0

Upgrades a project from reqo 1.x, including `@outloud/http` 1.0.0–1.0.3, reqo's
old name, once the agent has swapped it for `@outloud/reqo`. Every request method
takes `(url, options)`, with the body in `options.data` and query values in
`options.query`; `params` now holds path parameters.

## Changes

- `get`, `head`, `post`, `put`, `patch`, `delete` and their `$` variants take
  `(url, options)`. The body of `post`, `put` and `patch` moves to `data`, the
  query argument of `get` and `head` moves to `query`.
- `params` fills `{name}` placeholders in the URL instead of the query string,
  in every method's options, in `request()` and in the `config` that hooks get.
  Query values move to `query`.
- `$head` is removed: use `head`.
- The `http` export is removed: use `reqo`.
- `RequestError` no longer has `url`, `method`, `params` and `client`: read
  them from `error.config`.
- The response-type generic of `get`, `$get` and `head` moves from second to
  third place, as in the other methods: `<T, D, Type>`.
- Requests return a `Future` from `@outloud/future` 2, which has no `map`,
  `filter` and `forEach`.

## Steps

The steps search the whole project for method names that other HTTP clients
share, such as axios, ofetch or an AdonisJS router. Find the reqo clients
first and change only calls on them:

    grep -rnE '@outloud/reqo|createClient\(|new Client\(|extends Client\b' --include='*.ts' --include='*.tsx' --include='*.js' --include='*.mjs' --include='*.vue' --exclude-dir=node_modules .

A reqo client is the `reqo` or `http` import, a value from reqo's
`createClient()` or `new Client()`, or an instance of a class extending reqo's
`Client`, including when it is passed around or injected under another name.

A project function that wraps a reqo call, such as
`post(url, data, options)`, can keep its own signature: change the reqo call
inside it, not its callers. A `Client` subclass that overrides a method must
take the new `(url, options)` signature.

### 1. Import `reqo` instead of `http`

**Check:** `grep -rlE '@outloud/reqo' --include='*.ts' --include='*.tsx' --include='*.js' --include='*.mjs' --include='*.vue' --exclude-dir=node_modules . | xargs grep -nHE '\bhttp\b($|[^:])'`. Skip when no file imports `http` from `@outloud/reqo`.

Before:

    import { http } from '@outloud/reqo'

    await http.$get('/users')

After:

    import { reqo } from '@outloud/reqo'

    await reqo.$get('/users')

Rename every use of the import in that file.

### 2. Move request bodies into `data`

**Check:** `grep -rnE '\.\$?(post|put|patch)(<[^(]*>)?\(' --include='*.ts' --include='*.tsx' --include='*.js' --include='*.mjs' --include='*.vue' --exclude-dir=node_modules .` and keep the calls on a reqo client that pass more than the URL. Skip when none do.

Before:

    await reqo.post('/users', { name: 'John' })
    await reqo.$post('/users', body, { timeout: 5000 })
    await api.$patch<User>(`/users/${id}`, formData)
    await api.$put('/users/1', undefined, { headers })

After:

    await reqo.post('/users', { data: { name: 'John' } })
    await reqo.$post('/users', { data: body, timeout: 5000 })
    await api.$patch<User>(`/users/${id}`, { data: formData })
    await api.$put('/users/1', { headers })

A two-argument call can still typecheck in v2: the body is read as options and
never sent. That happens when the body is typed `any` or `Record<string, any>`,
or shares a key with the options, such as `data`, `headers`, `query`, `params`
or `timeout`. Change every match, whether the compiler complains or not.

### 3. Move query arguments of `get` and `head` into `query`

**Check:** `grep -rnE '\.\$?(get|head)(<[^(]*>)?\(' --include='*.ts' --include='*.tsx' --include='*.js' --include='*.mjs' --include='*.vue' --exclude-dir=node_modules .` and keep the calls on a reqo client that pass more than the URL. Skip when none do.

Before:

    await reqo.get('/users', { limit: 10 })
    await reqo.$get('/users', filters, { timeout: 5000 })
    await reqo.$get('/users', undefined, { headers })
    await reqo.head('/users', { active: true })

After:

    await reqo.get('/users', { query: { limit: 10 } })
    await reqo.$get('/users', { query: filters, timeout: 5000 })
    await reqo.$get('/users', { headers })
    await reqo.head('/users', { query: { active: true } })

As in step 2, a query typed `any` or `Record<string, any>` still typechecks as
options, and the request goes out without it. Change every match.

### 4. Rename `params` to `query`

**Check:** `grep -rnE '\bparams\b' --include='*.ts' --include='*.tsx' --include='*.js' --include='*.mjs' --include='*.vue' --exclude-dir=node_modules .` in the files that use a reqo client. Skip when none is a reqo option or a hook's `config.params`.

In 1.x, `params` held query values wherever it appeared: in the options of
`request()`, `delete`, `$delete`, and of `post`, `put` and `patch` after their
body, and as `config.params` wherever reqo hands back a config: in `init` and
`request` hooks and on `error.config`. Rename each to `query`, including in the
options moved in step 2.

Before:

    await reqo.request({ method: 'GET', url: '/users', params: { limit: 10 } })
    await reqo.$delete('/users/1', { params: { force: true } })
    await reqo.$post('/users', { data: body, params: { notify: true } })

    api.on('request', (config) => {
      config.params.token = token
    })

After:

    await reqo.request({ method: 'GET', url: '/users', query: { limit: 10 } })
    await reqo.$delete('/users/1', { query: { force: true } })
    await reqo.$post('/users', { data: body, query: { notify: true } })

    api.on('request', (config) => {
      config.query.token = token
    })

The old code still typechecks, and its values silently drop out of the URL,
since `params` now only fills `{name}` placeholders. Keep template-literal URLs
such as `` `/users/${id}` ``: they work as before. A reqo URL that contains
literal `{word}` text now has it replaced by `params.word` or an empty string;
encode such braces as `%7B` and `%7D`.

### 5. Replace `$head`

**Check:** `grep -rnE '\.\$head(<[^(]*>)?\(' --include='*.ts' --include='*.tsx' --include='*.js' --include='*.mjs' --include='*.vue' --exclude-dir=node_modules .`. Skip when nothing matches.

`$head` resolved to the empty body of a HEAD response. Call `head` and read the
response instead, applying step 3 to its arguments.

Before:

    await reqo.$head('/users')

After:

    const response = await reqo.head('/users')

    response.status

### 6. Pass the response-type generic third

**Check:** `grep -rnE '\.\$?(get|head)<[^(]*,[^(]*>\(' --include='*.ts' --include='*.tsx' --include='*.js' --include='*.mjs' --include='*.vue' --exclude-dir=node_modules .` and keep the calls on a reqo client with two type arguments, ignoring commas inside a nested type such as `Record<string, User>`. Skip when none do.

Before:

    await reqo.$get<Blob, 'blob'>('/file', undefined, { responseType: 'blob' })

After:

    await reqo.$get<Blob, any, 'blob'>('/file', { responseType: 'blob' })

The old order still typechecks: the second type argument becomes the body type
and the response type falls back to the default, so `data` is typed as the
first argument whatever `responseType` says, such as `T` instead of `undefined`
for `false`.

### 7. Read request details from `error.config`

**Check:** `grep -rnE '\.(url|method|params|client)\b' --include='*.ts' --include='*.tsx' --include='*.js' --include='*.mjs' --include='*.vue' --exclude-dir=node_modules .` and keep the reads on a reqo `RequestError`: in `catch` blocks around reqo calls, after `reqo.isError()` or `instanceof errors.RequestError`, and in `error` hooks. Skip when none do.

| 1.x | 2.0 |
| --- | --- |
| `error.url` | `error.config.url` |
| `error.method` | `error.config.method` |
| `error.params` | `error.config.query` |
| `error.client` | `error.config.id` |

Before:

    if (reqo.isError(error)) {
      logger.warn({ url: error.url, client: error.client }, error.message)
    }

After:

    if (reqo.isError(error)) {
      logger.warn({ url: error.config.url, client: error.config.id }, error.message)
    }

The compiler catches these only where the error is typed as `RequestError`;
on an `any` or a cast they read `undefined`. Code that logs the error's own
fields, such as `{ ...error }`, loses them too: log `error.toJSON()`, which
still has `client`, `url`, `method` and `params`, and now `query`. `status`,
`code`, `data` and `response` are unchanged.

### 8. Drop the `Future` array helpers

**Check:** `pnpm typecheck` reports that `map`, `filter` or `forEach` does not exist on type `Future`, or `package.json` lists `@outloud/future`. Skip when neither.

Await the request, then use the array methods.

Before:

    const names = await reqo.$get<User[]>('/users').map((user) => user.name)

After:

    const names = (await reqo.$get<User[]>('/users')).map((user) => user.name)

A callback that returns a promise needs `Promise.all` around the mapped array.
When the project depends on `@outloud/future` itself, bump it to `^2`, which
reqo 2 uses, so both share one `Future` type, and apply the same change to
the project's own futures.

## Verify

- `pnpm typecheck` passes.
- `grep -rnE '\.\$head(<[^(]*>)?\(' --include='*.ts' --include='*.tsx' --include='*.js' --include='*.mjs' --include='*.vue' --exclude-dir=node_modules .` finds no reqo call.
- The searches of steps 2 and 3 find no reqo call with a second argument that
  isn't an options object, nor any with a third argument.
- No reqo option or hook config uses `params` except to fill `{name}`
  placeholders in the URL.
- The project's tests pass.
